# Changelog

## v0.2.26 - 2026-08-06

### Shared bounded GitHub transport

- Advanced the immutable Dust Wave Platform pin to `v0.23.0`
  (`a0006c3e0c3f8ab814387491753989956adbbe94`) and replaced the local GitHub
  transport copy with the characterized Worker Core client.
- Preserved Podcast-owned repository, branch, publication schema, commit,
  authorization, credential, side-effect, deployment, and rollback policy.
- Reconciled the README, package map, roadmap, and changelog with the active
  release and exact independently reversible Platform boundary.
- Made the FFmpeg rendition processor regression portable to workspace paths
  containing spaces by using Node's canonical file-URL conversion, and report
  spawn errors explicitly instead of an unhelpful `undefined` failure.

## v0.2.25 - 2026-08-06

### Shared HTTP and validation primitives

- Advanced the immutable Platform pin to `v0.20.0` and adopted bounded request
  validation, managed provider-fetch timeout, and policy-injected CORS/JSON
  response primitives after consumer characterization.
- Removed the superseded local transport copies while retaining Podcast-owned
  schemas, authorization, allowed origins, CSRF, cache, retry, storage,
  credentials, deployment, and rollback policy.

## v0.2.24 - 2026-08-06

### Shared Resend webhook verification

- Advanced the immutable Platform pin to `v0.16.0` and adopted the bounded
  raw-body Resend/Svix signature verifier.
- Retained Podcast-owned templates, recipients, consent, delivery journal,
  suppression, provider transport, retry policy, credentials, routes, webhook
  effects, deployment, and rollback.

Earlier release history remains available through immutable Git tags and the
repository commit history.
